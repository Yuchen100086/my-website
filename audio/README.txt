这个文件夹里放的是网站右下角云朵播放的背景音乐。

当前文件
--------
    haoxiang-wan-yuanshen.mp3      《好想玩原神》

打开网站任意页面，点击右下角的云朵就会播放，再点一次暂停。

想换歌怎么办
------------
1. 把新文件放进这个文件夹；
2. 改 script.js 顶部的 BGM_SRC，指向新文件名即可。

其他提示
--------
- 建议用 MP3 格式，几乎所有浏览器都支持；
  文件别太大，超过 50MB 推送到 GitHub 会比较吃力（100MB 会被拒绝）。
- 音频是点击云朵后才开始播放的，这符合浏览器对自动播放的限制。
- 如果点了云朵没反应，页面右下角会弹一个小气泡提醒，
  那说明文件缺失或文件名对不上。
- 注意版权：请确认你有权使用该音频，公开仓库里放商业音源可能收到投诉。
